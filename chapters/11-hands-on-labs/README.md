# Hands-On Labs

These labs connect the book's guidance to small, repeatable exercises. Run them on a disposable local or staging site; they are deliberately scoped so each lab teaches one operational boundary.

```text
Site plugin lab      → safe custom-code structure
Webhook lab          → signed, idempotent asynchronous events
Cache validation lab → correct public/dynamic cache behavior
Release lab          → repeatable deployment verification
```

Each lab ends with validation and rollback prompts. Treat the code as a starting point, not copy-paste production configuration.
